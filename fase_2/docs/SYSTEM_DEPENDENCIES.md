# Dependencias de sistema (no incluidas en requirements.txt)

Instalar con apt antes de correr el script:

    sudo apt install ghostscript qpdf tesseract-ocr tesseract-ocr-spa poppler-utils

- ghostscript   → normalización de PDF y reparación de Forms (AcroForm)
- qpdf          → reparación de estructura PDF (proveedor Pakar)
- tesseract-ocr → motor OCR
- poppler-utils → pdf2image / rasterizado de páginas
